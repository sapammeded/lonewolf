# Kontribusi

1. Fork, buat branch `fitur/nama-modul`.
2. Jaga gaya kode: satu fungsi per fitur, tanpa dependensi baru kalau stdlib cukup.
3. Setiap modul baru wajib punya jalur non-root, atau tandai jelas butuh root.
4. Pastikan `python -m py_compile lonewolf.py` lolos.
5. Buka pull request dengan penjelasan singkat dan contoh output.
